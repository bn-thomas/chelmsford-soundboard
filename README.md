# Chelmsford Draft Soundboard

A single self-contained page of draft-night sound effects, linked from the league
draft board. Open it, tap a button, or press the matching number key.

Every sound is synthesized in the browser with the Web Audio API — there are no
audio files, no downloads and no third-party requests, so nothing here is
anyone else's copyrighted audio.

On iPhone, turn the ringer switch on: iOS silences Web Audio when muted.

Generated by the Fantasy Football Hub (`backend/services/soundboard.py`); edit it
there, not here.
